# Gonzales Vision Clinic – Patient Mobile App

A Flutter-based mobile application developed for **Gonzales Vision Clinic**, designed to make eye-care services more accessible and convenient for patients.

The application allows patients to manage appointments, explore eyewear, monitor transactions, and communicate with clinic support through a single mobile platform.

## ✨ Features

### 📅 Appointment Management
- Book clinic appointments.
- View upcoming and previous appointments.
- Check appointment availability.
- Cancel eligible appointments.
- Review appointment details before confirmation.

### 👓 Eyewear & Virtual Try-On
- Explore available eyewear.
- Access the clinic's virtual try-on experience.

### 🎫 Patient Support Center
- Submit support tickets.
- View ticket status and priority.
- Communicate with clinic administrators.
- Send image attachments.
- View conversation history and read receipts.
- Cancel eligible support tickets.

### 💳 Transaction History
- View patient transaction records.
- Review transaction details.

### 👤 Patient Account
- Patient registration and login.
- Secure session management.
- Profile viewing and management.
- Remember Me functionality.

## 🛠️ Technologies Used

- **Flutter** – Mobile application development
- **Dart** – Programming language
- **Node.js & Express.js** – Backend API
- **MySQL** – Database
- **REST API** – Client-server communication
- **JWT Authentication** – Patient authentication

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android Emulator or a physical Android device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/maningas-dot/maningas-mobile-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd maningas-mobile-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

**Note:** The application requires access to the configured Gonzales Vision Clinic backend API. Make sure the API configuration is correct before running the app.
